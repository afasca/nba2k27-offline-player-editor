# NBA 2K27 离线球员编辑器

> ⚠️ **必须离线运行游戏。** 本工具仅用于本地离线游戏。

这是针对特定 NBA 2K27 游戏版本制作的 Windows 球员名单编辑器。它直接修改正在运行的游戏内存，不修改游戏文件。游戏更新后，内存结构可能变化，届时应停止使用并重新验证。

## 功能

- 按联赛和球队查找球员，显示球队与总评；可识别游戏编辑器当前球员。
- 修改球员资料、身高、臂展、能力、徽章、倾向、动作等字段；部分字段支持批量修改。
- 分别复制球员数据和外貌 DNA 至单人或整队。
- 浏览、分类和修改游戏内战术手册。
- 在战术手册右侧用 Ctrl/Shift 多选战术，批量加入空槽；在左侧多选槽位后批量删除。整批操作可一次撤销。
- 保存前记录备份，可撤销本次修改。

## 使用

1. **断开网络，以离线方式启动游戏。**
2. 打开球员名单或游戏内球员编辑器，然后运行 `NBA2K27_PlayerEditor.exe`。
3. 选定球员或使用“识别游戏当前球员”，修改后点击保存。修改名单后，请在游戏内完成相应保存。

当前版本按本机 `F:\game\NBA2K27\NBA2K27.exe` 的游戏构建定位进程。若游戏路径或版本不同，请先修改源码中的 `GAME_PATH`，重新验证内存布局，再构建程序。

身高和臂展在目前确认的数据结构中各占 15 位，以 0.01 厘米存储，因此可输入范围上限为 **327.67 厘米**。游戏模型对超过菜单范围的数值是否生效，仍需在游戏中验证。直接去掉输入检查无法突破此数据结构的上限。

## 从源码构建

需要 Windows、Python 3.13，以及 `requirements.txt` 中的依赖。执行：

```powershell
python -m pip install -r requirements.txt
python -m PyInstaller --noconfirm NBA2K27_PlayerEditor.spec
```

构建产物位于 `dist\NBA2K27_PlayerEditor.exe`。源码、字段定义和战术目录均包含在仓库中；游戏文件不包含在内。
