# NBA 2K27 离线球员编辑器

> ⚠️ **必须离线运行游戏。** 本工具仅用于本地离线游戏。

这是针对特定 NBA 2K27 游戏版本制作的 Windows 球员名单编辑器。它直接修改正在运行的游戏内存，不修改游戏文件。游戏更新后，内存结构可能变化，届时应停止使用并重新验证。

## 功能

- 深色界面、黄色主操作按钮和球员信息卡；主窗口与编辑弹窗统一配色。
- 按联赛和球队查找球员，每支球队显示游戏内的队色徽标；可按姓名、编号或球队缩写搜索。
- 通过游戏内存识别游戏编辑器当前球员，不截图、不使用 OCR；普通识别扫描编辑器对象所在内存区域，深度识别扫描全部可读区域。
- 修改球员资料、身高、臂展、能力、徽章、倾向、动作等字段；能力值可编辑范围为 25–125，球员总评仍按游戏规则最高显示 99。部分字段支持批量修改。改过但未保存的项会高亮，切换球员或退出前会提示保存。
- 分别复制球员数据和外貌 DNA 至单人或整队，目标列表显示球队徽标与总评。
- 浏览、分类和修改游戏内战术手册。战术按游戏数据分为「打法 → 细分」两级，例如投篮跑位 → 三分 / 中距离、空切 → 空接 / 空切、挡拆 → 挡拆持球 / 挡拆外弹 / 挡拆顺下、背身 → 低位 / 高位 / 后卫背身，另有单打、手递手和发球战术；可按打法、细分、位置筛选，也可直接搜索「三分」「空接」等细分名称。关联位置先列主攻球员。「空接」依据战术名中的 ALLEY / LOB 标出，其余分类均读取自游戏战术记录。
- 在战术手册右侧用 Ctrl/Shift 多选战术，批量加入空槽；在左侧多选槽位后批量删除。整批操作可一次撤销。
- 「动作」和「战术手册」页可保存、载入预设，省去重复设置。动作预设可保存全部动作，也可只存投篮、控球等一类；载入只填入输入框，点「保存修改」才写入游戏。手册预设可保存整本或左侧所选槽位；载入时选「替换当前手册」（按原槽位还原）或「追加到空槽」（跳过手册里已有的战术），整批可一次撤销。预设保存在 `文档\NBA2K27_PlayerEditor_Backups\presets.json`，可复制到其他电脑使用。
- 保存前记录备份，可撤销本次修改。

## 使用

1. **断开网络，以离线方式启动游戏。**
2. 打开球员名单或游戏内球员编辑器，然后运行 `NBA2K27_PlayerEditor.exe`。
3. 选定球员或使用“内存识别当前球员”，修改后点击保存。修改名单后，请在游戏内完成相应保存。

程序按进程名 `NBA2K27.exe` 查找游戏，与安装位置无关（Steam 或其他目录均可）。内存偏移都相对于游戏主模块，因此只要求游戏**版本**相同：程序会读取游戏的构建信息，并在读取前校验名单结构；版本不同且结构不符时会提示并停止读取，不会写入。

快捷键：Ctrl+F 搜索，Enter 选中第一名，Ctrl+D 识别当前球员，Ctrl+S 保存，F5 重新读取。窗口大小和位置会自动记住；出错信息记录在 `文档\NBA2K27_PlayerEditor_Backups\editor.log`。

身高和臂展在目前确认的数据结构中各占 15 位，以 0.01 厘米存储，因此可输入范围上限为 **327.67 厘米**。游戏模型对超过菜单范围的数值是否生效，仍需在游戏中验证。直接去掉输入检查无法突破此数据结构的上限。

“身体”页提供两个便捷按钮：按身高 × 1.4 填臂展、按臂展 ÷ 1.4 填身高。按钮仅填写输入框，仍须自行点击“保存修改”；1.4 是换算参考值，并非已证实的游戏模型比例。

## 从源码构建

需要 Windows、Python 3.13，以及 `requirements.txt` 中的依赖。执行：

```powershell
python -m pip install -r requirements.txt
python -m PyInstaller --noconfirm NBA2K27_PlayerEditor.spec
```

构建产物位于 `dist\NBA2K27_PlayerEditor.exe`。源码、字段定义和战术目录均包含在仓库中；游戏文件不包含在内。
